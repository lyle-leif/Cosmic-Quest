# Cosmic Quest — Credits

Cosmic Quest is a Java study battle game developed by **NeuroLink** for
**OOP 101 at Batangas State University**.

## Project team

- **Lyle** — repository owner and development lead from session S04 onward.
- **Jhon Moises** — project team member.
- **Angelo** — project team member.

Full names, GitHub profiles, and assigned responsibilities are listed in the
[README's Team Members section](README.md#team-members).

## Software and tools

- **Java 21** — programming language and runtime.
- **libGDX** — game framework, Scene2D interface, graphics, audio, and preferences.
- **LWJGL 3** — desktop backend and native bindings.
- **gdx-video** — prologue video playback.
- **gdx-liftoff** — initial project generation.
- **Gradle and the Gradle Wrapper** — builds, tests, and packaging.
- **JUnit 5** — automated testing.
- **Gson** — JSON processing in the AI module.
- **Construo** — desktop distribution tooling configured in the build.

These projects are maintained by their respective contributors. Preserve the
licence and notice files supplied with dependencies when distributing the game.

## Optional AI services

- **Google Gemini** — lesson-based question generation.
- **Groq** — fallback question generation through an OpenAI-compatible endpoint.

The game uses local questions when online providers are unavailable.
The team supplies its own API keys in the local `config.properties` file.

## Fonts

The six bitmap font pairs in `assets/ui/fonts/` are `font_small`, `font_body`,
`font_medium`, `font_large`, `font_title`, and `font_huge` (`.fnt` and `.png`).

Earlier project notes identify Palatino and Trebuchet as the source fonts. The bitmap
metadata uses internal asset names, so the exact font files and their
redistribution permissions still need confirmation. Record the confirmed
font families, creators, sources, and licences here, or update these credits
if the fonts are replaced.
